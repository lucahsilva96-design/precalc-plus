MÓDULO 03 · SEGUNDO GRAU

Bhaskara em dois passos.

Uma equação do segundo grau tem a forma ax² + bx + c = 0, com a ≠ 0. O discriminante Δ revela quantas raízes reais existem e a fórmula de Bhaskara entrega seus valores.

01 · CALCULE O DISCRIMINANTE

Δ = b² − 4ac

O discriminante Δ (delta) concentra toda a informação sobre as raízes antes de calculá-las. Ele só usa os coeficientes a, b e c.

2x² − 7x + 3 = 0

a = 2, b = −7, c = 3. Então:

Δ = (−7)² − 4 · 2 · 3 = 49 − 24 = 25

Δ > 0 → duas raízes reais distintas.  Δ = 0 → raiz dupla.  Δ < 0 → sem raiz real.

02 · FÓRMULA DE BHASKARA

x = (−b ± √Δ) ÷ (2a)

Com Δ calculado, aplique a fórmula duas vezes: uma com + e outra com −.

x = (7 ± √25) ÷ 4 = (7 ± 5) ÷ 4

  1. x₁ = (7 − 5) ÷ 4 = 2 ÷ 4 = ½
  2. x₂ = (7 + 5) ÷ 4 = 12 ÷ 4 = 3

Nesta prática: raízes inteiras de −6 a 6; a ∈ {−3,…,−1,1,…,3}. Δ é sempre um quadrado perfeito, portanto √Δ é inteiro.

03 · VERIFICAÇÃO

Substitua cada raiz.

Uma raiz x₀ satisfaz a equação quando ax₀² + bx₀ + c = 0. Troque x por x₁ e por x₂ e confirme que ambos os resultados são zero.

2 · (½)² − 7 · ½ + 3 = ½ − 3½ + 3 = 0 ✓

2 · 3² − 7 · 3 + 3 = 18 − 21 + 3 = 0 ✓

Agora é sua vez.

Passo 1: calcule Δ. Passo 2: encontre x₁ e x₂.
